# CaseBridge

## Citizen–Police Case Management System

CaseBridge is a web-based case management platform that connects citizens and police through a shared digital system.

## Features

### Citizen
- Citizen registration and login
- Submit complaints/cases
- Automatic Case ID generation
- View submitted cases
- Track case status
- View police updates and case timeline

### Police
- Secure police login
- Police dashboard
- View citizen cases
- Update case status
- Send investigation updates to citizens

## Technologies Used

- HTML
- CSS
- JavaScript
- Supabase Authentication
- Supabase PostgreSQL Database
- GitHub

## Database

The application uses Supabase to store:
- Citizen cases
- Case status
- Police updates
- Case timeline information
